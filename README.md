# Gerenciador de Tarefas POO

Sistema de gerenciamento de tarefas em Python utilizando **Programação Orientada a Objetos (POO)**. Permite adicionar, listar, remover e favoritar tarefas com informações opcionais de matéria e observações.

## Funcionalidades

- Adicionar tarefas com nome, matéria e observações opcionais.
- Listar todas as tarefas cadastradas.
- Remover tarefas pelo índice.
- Favoritar ou desfavoritar tarefas.
- Indicação visual de tarefas favoritas com ⭐.

## Estrutura do Projeto

- `diversos.py`: tratamento de inputs e validação de campos obrigatórios.
- `gerenciador.py`: classe principal que gerencia as tarefas.
- `indice.py`: funções auxiliares para seleção de opções e índices.
- `main.py`: interface de menu do usuário.
- `teskMolde.py`: molde de tarefas utilizando POO.
